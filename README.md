One brutally honest but still polite out-of-office email auto-reply, written for make.fun's "The Painfully Honest Out-of-Office" bounty. A single sentence of 193 characters that admits the truth every employee only says privately — the laptop was left at home on purpose, because the inbox had quietly become the actual job — and still thanks the sender and promises a reply, so a manager would let it stand.

> I'm out of office until Monday, and honestly, I left my laptop at home on purpose — 400 unread emails had quietly become my actual job, so thank you for your patience; I'll reply when I'm back.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `./output/entry.txt` if `/output` is not writable) and prints it. The entry is fixed text, so every run produces the exact same 193-character line — deterministic, no network, no secrets.
